# Example configs

| File | Use it for |
| --- | --- |
| [`cursor-mcp.json`](cursor-mcp.json) | Cursor: copy to `.cursor/mcp.json` in your project, or `~/.cursor/mcp.json` for every project |
| [`vscode-mcp.json`](vscode-mcp.json) | VS Code: copy to `.vscode/mcp.json` |
| [`claude-code.sh`](claude-code.sh) | Claude Code: adds the server, then run `/mcp` to sign in |
| [`stdio-mcp-remote.json`](stdio-mcp-remote.json) | Any client that only speaks stdio, through the `mcp-remote` bridge |

Claude (web, desktop, mobile) and ChatGPT are set up in their settings instead: see [Connect your assistant](../README.md#connect-your-assistant).
